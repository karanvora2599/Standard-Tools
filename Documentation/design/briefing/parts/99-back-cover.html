The agent chooses. The library computes.
Every call can be replayed.
Typed

One Pydantic model in, one out, for every one of the 266 tools. Unknown arguments are refused, and every refusal names the fix.

Scoped

Twelve runtimes, each its own dispatch table. A client is served one, and a tool it was not given is unroutable.

Measured

Planted answers, a second oracle per kernel, fuzzing, mutation testing, and the results that did not help kept beside the ones that did.
