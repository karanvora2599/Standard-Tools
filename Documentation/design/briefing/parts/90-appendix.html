BAppendix B · Glossary

TermMeaning here
RuntimeAn execution boundary with its own dispatch table. A tool from another runtime is unroutable through it.
CategoryA narrower grouping within a runtime, used to scope a session further.
Analysis facadeThe 217 tools get_agent_tools() returns, routed by dispatch().
ReferenceAn sqt://kind/run_id/name string standing for a published bulk value, its kind checked on resolve.
Decision recordOne JSONL entry per dispatched call: inputs, data hashes, execution path, output hash, chained to the one before.
CheckpointAn Ed25519 signature over a day's chain endpoint, verifiable with the public key alone.
Temporal contractWhat a source can promise about when its facts became knowable, asked before fetching.
BundleSeveral frames and the contract each was fetched under, validated as one unit.
Purging · embargoDropping training rows whose labels overlap the test period, by label end date, and a gap after it.
Deflated SharpeA Sharpe ratio corrected for the number of strategies tried and for non-normal returns.
PBOThe probability of backtest overfitting: how often the in-sample winner ranks below the median out of sample.
ThinningServing a shortened schema for an expensive tool, with describe_tool returning the full one.
HAS_CPPEach module's flag for whether its C++ kernel is in use; toggled to time both paths of the same call.
Planted answerA test input built so the right output is known by construction, rather than recorded from a past run.
Metamorphic relationA rule saying two different inputs must give the same answer, which catches a consistently wrong function.
Mutation testingPlanting a deliberate defect and requiring the suite to fail, which shows the tests would notice one.
