18Getting started

Python 3.10 or later. pip install . builds the C++ extension when a toolchain is present and installs the pure-Python package when it is not; every tool works either way.

pip install .                              # the library, with the extension where it can build
pip install "standard_quant_tools[mcp]"    # adds the sqt-mcp server
pip install "standard_quant_tools[signing]"  # adds Ed25519 checkpoint signing
pip install "standard_quant_tools[polars]"   # adds optional polars interop

From Python

from standard_quant_tools.agent.tools import dispatch, get_agent_tools

schemas = get_agent_tools()      # the analysis facade's function-calling schemas
risk = dispatch("analyze_stock_risk", {"symbol": "NVDA", "period": "1y"})

dispatch validates the arguments against the tool's input model and returns its result as a dictionary. An unknown argument is refused, not ignored.

Over MCP

sqt-mcp --runtime research       # serve one runtime to the client
sqt-mcp --runtime backtest
sqt-mcp --print-budget           # what each runtime and category costs a client's context

Any MCP client launches sqt-mcp with the runtime it should be served. Thinned schemas are the default, and describe_tool returns any of them in full.

Configuration and secrets

Provider settings live in a .env file that is never committed, or in a CI system's encrypted secrets under the same names; load_env() is a harmless no-op when there is none. The audit trail writes where SQT_AUDIT_DIR points, and SQT_AUDIT_ENABLED=0 turns record writes off.

19Limits, stated plainly

What the library does not do, or does only partly. Each limit is also stated where it bites, in the tool's own description or refusal.

LimitWhat it means in practice
No option-chain dataThe derivatives tools take quotes as arguments. Nothing in the library fetches a chain, and no description implies otherwise.
The whole surface does not fit a session727 KB of schema is about 186,000 tokens. A client is served one runtime, by design; serving all twelve is a diagnostic.
An audit trail is not certificationIt detects tampering; it does not prevent it, and it is not a regulatory attestation. sqt keygen is for local development; a real deployment signs through its own key service.
In-sample is in-sampleAn allocation's reported Sharpe, a factor model's fit and a full-refit model's scores are in-sample, and are labelled so. Out-of-sample figures come from the walk-forward tools.
pandas is requiredPolars interop covers a growing subset of functions; pandas stays the default and required backend.
Live vendor behaviourThe suite runs on planted and recorded data. What a vendor's live feed does is established only with a live key, in the tests marked as needing one.
Correct is not usefulThe tests show a statistic is computed correctly and reproduces. Whether a strategy built on it makes money is not something any test, or this document, asserts.
Not investment advice

Standard Quant Tools is a software library. Nothing in it, or in this briefing, is a recommendation to buy or sell anything, and the planted-data results in Part IV describe what a method does when the truth is known, not what it will earn.
